# 桌游规则遗忘点卡片库 · 聚会主持台

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 聚会主持台

在卡片库下方新增了主持台面板：

- **自动编排**：输入到场人数、总时长、开始时间和复习重点，自动把收藏拆成多桌多局流程。每局包含讲解、准备、游玩、计分、收纳五段时间（按复杂度与规则条目数估算）。
- **排序规则**：候选按遗忘风险（未玩天数 + 遗忘点数量）优先、讲解成本从低排序，复习重点命中的规则类别加分；同一桌连续两局不会重复同一款。
- **微调**：场次卡片可锁定（重新编排时保持不动）、下拉替换、拖拽换桌换序；任何改动立即重排时间。“连续不重复”在所有路径上都被强制：生成时排不出不同款就停手，拖拽造成相邻重复会被拦截，移除或拖出导致源桌相邻同款时会自动换一款修复（无可替换则整单取消），加载旧数据时也会自动清理。超出总时长时桌次和场次都会出现超时提示。
- **临场调整**：修改人数后重新编排（或点“迟到/缺席”），以及“中途插队加一局”，都会先自动把当前方案存入草稿箱再给出可执行新方案；草稿可随时恢复或删除。人数不符的插队会被拦下并说明原因。
- **撤销/恢复**：主持台的所有改动（重排、锁定、替换、拖拽、插队、导入、草稿操作）都可撤销与恢复。
- **导出/导入**：方案可导出为 JSON；导入时校验重复场次、时间冲突、人数不符、失效引用和超出实际桌数的非法桌号，任一问题都会整单拦截且不影响当前数据，导入成功后可用撤销回到导入前。

所有数据（收藏、规则、主持台方案、草稿）都保存在浏览器 localStorage，刷新后自动恢复。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
